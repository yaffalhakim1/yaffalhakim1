## Featured projects

### [Kerenzikov](https://github.com/yaffalhakim1/Kerenzikov-app): native app for coding agents
`Rust` · `GPUI` · `SQLite` · `Bun`

A Windows and Android fork of [egoist/waku](https://github.com/egoist/waku), focused on OpenCode and also working with Claude Code, Codex CLI, Amp and Cursor CLI.

- Desktop client talks to a standalone daemon over an authenticated, versioned WebSocket protocol; browser client types are generated from the Rust protocol.
- Local-first: projects, sessions and transcripts stay on your machine, no account needed.
- Signed releases with in-app auto-update, built and published through GitHub Actions.
- 570+ commits, GPLv3, with upstream credited and modifications documented.

### [term.habits](https://github.com/yaffalhakim1/habit-terminal): gamified habit tracker ([live demo](https://yaffalhakim1.github.io/habit-terminal/))
`React 19` · `TypeScript` · `Vite` · `TanStack Query` · `PWA`

A terminal-themed habit tracker with RPG-style XP, HP and streaks.

- Two-way sync with the Habitica API.
- Bring-your-own-key AI weekly review (OpenAI, Gemini, MiMo); keys never leave the browser.
- 15 themes, installable PWA, works offline, no backend.
- Auto-deployed to GitHub Pages on push.

### [opencode-mobile](https://github.com/yaffalhakim1/opencode-mobile): Android client for OpenCode
`Kotlin` · `Jetpack Compose` · `Material 3`

A native Android client for a self-hosted OpenCode server. Published as signed APK releases (Android 8.0+), with 15+ tagged versions so far.
